# KayaJob for Android

**Kaya mo 'yan.** The free all-in-one app for Filipino job seekers: track applications, prepare HR requirements, practice interviews with AI, know your real take-home pay, and get home safe with KayaNav.

## Download

Get the latest APK from **[Releases](https://github.com/jedgarf/KayaJob-Releases/releases/latest)**.

**Requirements:** Android 7.0 or newer.

## How to install

1. Download `KayaJob-vX.Y.Z.apk` from the latest release on your phone.
2. Open it. If Android asks, allow installing apps from your browser or file manager.
3. Tap **Install**, then open KayaJob and create your free account.

**Updating?** Install the new APK over the old one. Your data is saved to your account, so nothing is lost.

## Verify your download (optional)

Each release lists the SHA-256 of its APK. To check it on a computer:

```bash
shasum -a 256 KayaJob-v1.0.0.apk
```
